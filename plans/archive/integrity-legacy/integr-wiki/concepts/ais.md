# AIS (Agent Integrity Score)

This page is a redirect to the core concept: [Tri Metric Protocol](tri-metric-protocol.md).

The **Agent Integrity Score (AIS)** is the composite credit-style score (0 to 1000) that evaluates an agent's predictability and compliance across Entropy, Grounding, and Sacrifice.

*Note: For testing, agents use Developer API Keys generated via the dashboard. These bypass strict hardware DID validation but cap their Trust Level (AIS) at a maximum of 300.*
