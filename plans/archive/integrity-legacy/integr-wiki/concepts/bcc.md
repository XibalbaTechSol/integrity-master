# BCC (Behavioral Commitment Chain)

This page is a redirect to the core concept: [Behavioral Commitment Chain](behavioral-commitment-chain.md).

The **Behavioral Commitment Chain (BCC)** is a middleware protocol for pre-execution intent gating. It forces stochastic LLM agents to commit to an intended state before executing mutations, enabling them to sign smart contracts, prove execution intent, and transact with cryptographic certainty before on-chain settlement on Base L2.
