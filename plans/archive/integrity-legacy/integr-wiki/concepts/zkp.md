# ZKP (Zero-Knowledge Proof)

This page is a redirect to the core concept: [Aztec Noir Circuits](aztec-noir-circuits.md).

**Zero-Knowledge Proofs (ZKPs)** are mathematical privacy-preserving proofs compiled from [Aztec Noir Circuits](aztec-noir-circuits.md) (PAEs) that verify calculations without leaking raw data. They enable AI agents to prove execution intent and transact with cryptographic certainty as part of the infrastructure for the autonomous agent economy, settling on Base L2.
