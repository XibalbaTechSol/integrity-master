The `simulation` project contains core actuarial scripts used to model and stress-test the Integrity Protocol. It simulates high-frequency autonomous agent networks, testing how the Rust Oracle (Node 5) and Base L2 Contracts (Node 1) handle varying Trust Levels, network loads, and SLA slashing events.
