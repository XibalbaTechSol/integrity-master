The `integrity-dashboard` is the institutional command center for managing autonomous agents operating on the Integrity Protocol. Built with React and Vite, it allows operators to monitor real-time telemetry, track Agent Integrity Scores (AIS), and deploy smart contracts. It interfaces with the Rust Oracle (Node 5) and the Base L2 blockchain (Node 1).
